# Detalhes sobre a entrega 2

* Formulário de Contacto
-O formulário apresenta 3 campos de entrada: Nome, email e mensagem.
Todos os campos são verificados para saber se contêm texto e, especialmente
o email, um formato email válido (verificamos apenas a existência de texto
à esquerda do @ e se é um @(domínio) válido)


* Animações
-D3.js: Foi implementado uma animação com gráficos de barras na "Áreas de
Investigação". Este gráfico mostra as barras quando o botão "Saber mais" 
é pressionado e a imagem é recriada se o tamanho da janela for ajustado.

-Three.js: Foi implementado uma animação 3D rotativa com o logotipo do CACA que está presente quando a landing page é atualizada (loading page)



* Gestão de Eventos
-Botão "Saber Mais": Como foi mencionado acima, ao pressionar este botão
os conteúdos do gráfico de barras são criados.

-Scroll-to-top: Foi implementado um botão que permite ir para o topo da 
landing page. Este botão é visível ao dar scroll por 500px em relação ao 
topo e animação de scroll foi modificado para "smooth".

-Carrossel de imagens: Foi implementado um carrossel de imagens nas
"Parcerias" que permite alterar o parceiro que está visível ao pressionar
nos círculos "dots" por debaixo da imagem.


# Detalhes sobre a entrega 1

Descrição da identidade visual:
* Cores utilizadas:
    amarelo (Fundo): #FFEC58;
    azul (Texto,Fundo): #1B3577;
    branco(Texto, Fundo): #FFFFFF;
    amarelo escuro (Botões, Texto): #CE7F00;
    preto (Texto): #000000;
    cinzento escuro (Texto): #333333;
    azul claro (Botão): #3865D7;
    cinzento claro (Texto input): #808080;
    
* Fonte:
Kadwa (Texto geral)


Descrição:
-A identidade visual da landing page realizada baseia-se na simplicidade e legibilidade. Utiliza na maioria das circunstâncias cores simples com contraste significativo entre elementos e texto em tamanhos legíveis e com conteúdo de facil leitura.


Evolução das várias fases:
-Ambos o wireframe e o mockup foram realizados no figma, com o primeiro destes sendo basicamente apenas uma versão crude deste, a qual foi usada como base para a realização do mockup. O design do mockup segue fielmente o que foi apresentado no site, apresentando apenas eventuais diferenças imperceptíveis nas imagens.


Acessibilidade e legibilidade:
-Durante a realização deste projeto, teve-se o cuidado de usar fontes e elementos com tamanhos adequados ao seu dispositivo, bem como tornar responsivo para outras plataformas, sendo funcional em mobile, tablet e desktop.
