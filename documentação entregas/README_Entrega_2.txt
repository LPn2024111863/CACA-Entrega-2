# Detalhes sobre a entrega 2

* Formulário de Contacto
-O formulário apresenta 3 campos de entrada: Nome, email e mensagem.
Todos os campos são verificados para saber se contêm texto e, especialmente
o email, um formato email válido (verificamos apenas a existência de texto
à esquerda do @ e se é um @(domínio) válido)


* Animações
-D3.js: Foi implementado uma animação com gráficos de barras na "Áreas de
Investigação". Este gráfico mostra as barras quando o botão "Saber mais" 
é pressionado e a imagem é recriada se o tamanho da janela for ajustado.

-Three.js: Foi implementado uma animação 3D rotativa com o logotipo do CACA que está presente quando a landing page é atualizada (loading page)



* Gestão de Eventos
-Botão "Saber Mais": Como foi mencionado acima, ao pressionar este botão
os conteúdos do gráfico de barras são criados.

-Scroll-to-top: Foi implementado um botão que permite ir para o topo da 
landing page. Este botão é visível ao dar scroll por 500px em relação ao 
topo e animação de scroll foi modificado para "smooth".

-Carrossel de imagens: Foi implementado um carrossel de imagens nas
"Parcerias" que permite alterar o parceiro que está visível ao pressionar
nos círculos "dots" por debaixo da imagem.
